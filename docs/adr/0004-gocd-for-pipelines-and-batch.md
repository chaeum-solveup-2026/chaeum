# 빌드, 배포와 배치는 GoCD 한 곳에서 흐름을 본다

여러 파이프라인(API 빌드, 웹 빌드, 테라폼, 배포, 스모크 테스트)이 이어지는 흐름과 배치(대피소 데이터 수집)를 한 화면에서 보는 것이 중요하고, GitHub Actions 는 조직의 비공개 저장소 실행 시간 제한이 있다. 그래서 GoCD 를 앱 서버와 분리한 작은 NCP 서버에 두고(테라폼으로 생성), 파이프라인 설정은 YAML 로 저장소에서 관리하며, 대피소 데이터 수집은 GoCD 의 시간 트리거 파이프라인으로 돌린다. 조건부 배정 만료는 업무 로직이라 앱 안에서 처리한다. 지금은 도입을 보류한다(아래 결정 참고).

## Considered Options

- GitHub Actions: 운영 부담이 없지만 실행 시간 제한과, 워크플로 하나 안의 작업 그래프만 보인다
- GitHub Actions + NCP 자체 실행기: 시간 제한은 풀리지만 여러 파이프라인을 잇는 흐름은 볼 수 없다
- Argo CD: 쿠버네티스 전용이라 서버 1대 docker compose 구성에 붙일 곳이 없다

## 2026-10-28 결정

도입을 보류(deferred)한다. 지금은 GitHub Actions + NCP 자체 실행기와 앱 안 스케줄로 간다. GoCD 는 제품으로 가치를 보인 뒤 다시 검토한다.
