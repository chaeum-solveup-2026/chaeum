# 08: 본선 시연 시나리오와 발표 구성

Type: grilling
Status: resolved
Blocked by: 02, 07

## Question

본선 발표 10분과 질의 10분에서 어떤 시나리오로 시연하고, 발표자료는 어떻게 구성할까? 완성도, 확장성, 유용성 배점을 각각 어느 장면이 받쳐 주는가?

## Answer

2026-10-28 grilling 으로 결정(찬규님).

- 발표 10분 배분: 문제 1분(출처 있는 수치) / 차별점 1분(입력 마찰 제거, 연계 계층) / 라이브 시연 4분 / 유용성 1.5분(시범 참여 수, SUS, 실제 문장 F1, 예상 사용자 수) / 완성도와 확장성 1.5분 / 마무리 1분
- 시연은 실제 배포 주소로 라이브, 같은 흐름의 녹화 영상을 백업으로 준비
- 시연 흐름(하나의 이야기): 산불 다음 날 담당자가 휴대폰으로 엑셀 업로드와 대화방 문장 붙여넣기 -> 확인 필수 1건 고쳐 확정 -> 부족 목록 공개 -> 기부자가 모금 페이지 위젯에서 "담요 10장, 헌 옷 한 박스, 성인 기저귀 20팩" 입력 -> 기저귀는 조건부 배정, 담요는 다른 현장 안내, 헌 옷은 보류 -> 수령 확인 -> 현황판 갱신. 평시 모드는 30초 장면
- 오프라인 기록(비행기 모드 -> 복구 시 전송)은 기능은 만들고 장면은 20초 녹화 클립으로
- 데이터: 대피소는 15139148 실제 시설, 요청과 기부는 가상이며 화면에 "가상 요청" 표시. 지역은 시범 기관 지역, 없으면 연수구
- 확장성은 화면으로: CI/CD 흐름 화면(GoCD value stream map, 미채택 시 GitHub Actions), 인프라 코드로 다른 지자체에 복제하는 과정, 공개 API 문서와 위젯 붙이는 코드 한 줄, 로드맵(챗봇, 분류 모델, k3s)
- 질의 10분 대비 한 장(이어드림 차이, 개인정보, 규칙 파서 이유, 실제 기관 사용, 운영 비용, 문자 수신 범위). 재료는 적대적 리뷰
