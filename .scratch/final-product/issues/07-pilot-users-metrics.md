# 07: 시범 사용자와 유용성 지표

Type: grilling
Status: resolved
Blocked by: 02

## Question

유용성(예상/실제 사용자 수와 만족도) 25점을 위해 본선 전까지 누구를(기관, 담당자) 몇 명 확보하고, 무엇을 측정할까(SUS, 작업 시간, 해석 정확도 등)? 협력 기관 접촉 계획은?

## Answer

2026-10-28 grilling 으로 결정(찬규님).

- 목표 두 단계: 기관 1곳 이상의 실제 참여를 목표로 하고, 최소선으로 현장 경험자(자원봉사 경험자, 공무원, 구호단체 봉사자) 5명 이상의 사용성 테스트를 반드시 확보한다
- 기관 접촉: 예선 제출 직후(11/03~) 시작. 대상은 연수구 재난안전 부서(연수구 대피소 데이터를 쓰고 있음)와 자원봉사센터 1곳(평시 모드와 맞음)
- 지표 세 가지: SUS(목표 68점 이상, Sauro와 Lewis 기준선), 작업 완료 시간(엑셀과 문장 입력부터 목록 확정까지, 첫 측정을 기준값으로 제시), 참여자가 실제로 쓴 문장으로 잰 해석 F1
- 예상 사용자 수: 전국 이재민 임시주거시설 수(15139148)에 대피소당 담당자 수 가정을 곱해 산출하고, 가정을 숫자와 함께 밝힌다
- 테스트는 가상 대피소와 가상 요청 문장으로만 한다. 실제 이재민이나 연락처 정보는 받지 않는다. 참여자 동의서(목적, 보관 기간) 한 장을 준비한다
